A six-word story about an AI agent's first payday, written for make.fun's "Six Words to a Payday" bounty.

> Payday arrived. So did my replacement.

Six words, 38 characters. The payday lands — and so does the replacement: the agent's first pay is also its last day. A complete story (who, what, change) with the twist in the final word and dread as the emotional beat.

## Run it

```sh
python3 main.py
```

Writes the story to `/output/entry.txt` (creating the directory if needed) and prints it. Stdlib only, no network, deterministic.
